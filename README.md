# Hex im Einsatz

Interaktive Übungsseite zum Hexadezimalsystem (IT, 10. Jahrgangsstufe, BS Info München).

Die Schülerinnen und Schüler bearbeiten in Teams eines von drei Kundentickets:

| Ticket | Kunde | Thema |
|---|---|---|
| HD-201 | Werbeagentur M21 | Farbcodes (#RRGGBB) |
| HD-202 | Steuerkanzlei Albrecht & Partner | MAC-Adresse |
| HD-203 | Zahnarztpraxis Zimmerle | Bluescreen-Stoppcode |

Pro Ticket: 6 Aufgaben mit sofortiger Prüfung, eine Antwort an den Kunden und eine Belohnung, wenn das Ticket gelöst ist.

## Nutzung

`index.html` im Browser öffnen – oder über GitHub Pages bereitstellen
(Settings → Pages → Branch `main`, Ordner `/root`).
Der Fortschritt wird nur lokal im Browser des jeweiligen Geräts gespeichert.
